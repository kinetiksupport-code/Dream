# Capturas de verificación

Capturas reales de Chromium sobre el build de producción local. Los datos proceden exclusivamente de fixtures de contrato de Playwright: no son datos de usuarios ni certifican OAuth/IA en vivo.

Incluyen los nueve anchos solicitados en Exámenes (375, 390, 393, 430, 768, 834, 1280, 1440, 1728), detalle/plan/estudio/nuevo examen en móvil, tablet y desktop, modo oscuro, preguntas de selección/respuesta abierta/matemáticas, confirmación, resultado, repaso y Privacidad en Ajustes.

Referencias originales: `docs/design/exams`. La interfaz no dibuja barras de estado del sistema ni sustituye sus datos reales por los números de Figma. Los widgets de resultado muestran los datos devueltos por el motor existente y omiten métricas no disponibles.
