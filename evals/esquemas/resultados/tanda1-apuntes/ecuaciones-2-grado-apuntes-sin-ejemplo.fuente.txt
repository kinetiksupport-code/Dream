# Ecuaciones de segundo grado

Una ecuación de segundo grado tiene la forma ax^2 + bx + c = 0, con a distinto de 0.

Fórmula general: x = (-b ± √(b^2 - 4ac)) / 2a.

El discriminante es Δ = b^2 - 4ac:
- Si Δ > 0, hay dos soluciones reales distintas.
- Si Δ = 0, hay una solución doble.
- Si Δ < 0, no hay soluciones reales.

Ecuaciones incompletas:
- Si b = 0 (ax^2 + c = 0), se despeja x^2 y se hace la raíz: x = ±√(-c/a).
- Si c = 0 (ax^2 + bx = 0), se saca factor común: x(ax + b) = 0, así que x = 0 o x = -b/a.

Ejemplo: x^2 - 5x + 6 = 0. Aquí a = 1, b = -5 y c = 6. Δ = 25 - 24 = 1. Las soluciones son x = 3 y x = 2.

Propiedades de las soluciones: la suma es -b/a y el producto es c/a.

Errores típicos: olvidar el signo de b al sustituir, no dividir todo el numerador entre 2a y dividir entre x en ax^2 + bx = 0, con lo que se pierde la solución x = 0.
